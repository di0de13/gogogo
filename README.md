# LiveGrow 面试准备项目

这是一个面向字节跳动后端开发实习生（营收增长方向）面试准备的可运行项目与复盘资料库。

项目目标不是声称实现“亿级生产系统”，而是用一个可验证的直播营收增长场景，展示：

- Go 后端开发与工程质量；
- MySQL、Redis、Kafka 和最终一致性；
- 高并发、数据隔离、解耦和容灾意识；
- AI 辅助开发、Code Review、评测和安全边界；
- 能把 AI/算法背景迁移到业务系统的学习能力。

## 真实性约束

所有简历指标都必须来自实际测试，并明确测试环境；所有未实现的生产能力都使用“设计/模拟/演练”表述，不把本地实验冒充线上规模。
